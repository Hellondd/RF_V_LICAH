# 🎨 Подсистема Frontend: Модуль статических страниц и интерактивной фильтрации

Данный файл содержит техническую документацию клиентской части приложения «Россия в лицах», разработанной в рамках производственной практики. Модуль представляет собой автономный фронтенд-пакет, отвечающий за визуальный слой, архитектуру интерфейса в стилистике государственного праздника и клиентскую логику обработки данных.

Вся подсистема реализована на чистом стеке (Vanilla JS / CSS3 / HTML5) без сторонних фреймворков, что гарантирует мгновенную скорость загрузки, независимость от внешних CDN и полную готовность к дальнейшей интеграции в общую структуру проекта.

---

## 🎨 Визуальное решение и UX/UI концепция

Интерфейс спроектирован с упором на строгость, доступность контента и удобство чтения:
1. **Цветовая схема «Триколор»:** Основные управляющие элементы и навигационные кнопки сгруппированы в цветах флага России (Белый - Синий - Красный). Базовый дизайн использует глубокий синий (`#1f4e79`) для структурных блоков, приглушенный красный (`#d9383a`) для активных тегов и мягкий светлый фон (`#f5f8fa`) для снижения нагрузки на зрение.
2. **Контентная политика:** Исключены абстрактные формулировки и «вода». Информация подана в виде точных исторических фактов, цифр и верифицированных дат.
3. **Типографика:** Во всех текстовых файлах длинные тире заменены на стандартные дефисы ("-") для унификации отображения в любых браузерах и исключения сбоев кодировки.

## 🛠 Архитектура и функционал разработанных страниц

Интерфейс разделен на 4 разработанных контентных блока:

### 1. Главная страница (`index.html`)
* **Компоненты:** Приветственный Hero-баннер с триколор-кнопками быстрого перехода, информационный блок со ссылкой на статью 112 Трудового кодекса РФ (официальный нерабочий статус 12 июня) и адаптивная сетка из 6 карточек с ключевыми географическими и культурными фактами о масштабах страны.
* **Фиксация навигации:** Шапка сайта (`header`) имеет свойство `position: sticky` и остается доступной при любом уровне скроллинга страницы.

### 2. Лента истории праздника (`history.html`)
* **Компоненты:** Вертикальная интерактивная линия времени (Timeline), построенная на чистом CSS. Исторические карточки автоматически чередуются по сторонам (лево/право). Каждая точка привязана к конкретной вехе (1990, 1992, 1998, 2002 гг.) и описывает этапы изменения статуса праздника.

### 3. Карта регионов (`regions.html`)
* **Компоненты:** База данных из **10 детализированных карточек субъектов РФ** (Москва, Санкт-Петербург, Татарстан, Нижегородская, Новосибирская, Иркутская, Ярославская, Мурманская, Самарская области и Приморский край).
* **Интерактив:** Реализована поисковая панель, объединяющая текстовый поиск (по названию/городу) и фильтрацию по Федеральным округам через выпадающий список. Каждая карточка содержит уникальный верифицированный маркер `📌 ФАКТ` (достижения в машиностроении, логистике или географические рекорды).

### 4. Выдающиеся личности (`persons.html`)
* **Компоненты:** Интерактивный каталог деятелей, внесших доказанный вклад в развитие науки, космонавтики и медицины (Менделеев, Гагарин, Пирогов, Королев, Склифосовский, Курчатов).
* **Интерактив:** Блок кнопок-табов для мгновенного переключения категорий («Наука и Космос», «Медицина», «Технологии»).

## 🗂 Реализованная структура папки `frontend`

В общем репозитории проекта код фронтенда организован следующим образом:
```text
frontend/
├── index.html          # Главная страница (официальный статус, общие цифры и факты)
├── history.html        # Хроника праздника (интерактивная таймлайн-лента событий)
├── regions.html        # Карточки регионов с формой поиска и фильтрации
├── persons.html        # Каталог выдающихся деятелей с фильтрацией по сферам
├── css/
│   └── style.css       # Стилизация интерфейса, адаптивная сетка и UI-компоненты
└── js/
    └── main.js         # Скрипты фильтрации данных на стороне клиента (Vanilla JS)
```
📐 Техническая спецификация подсистемы
HTML5: Семантическая разметка  для обеспечения доступности интерфейса.

CSS3 (Grid & Flexbox): Полная адаптивность страниц. Сетки карточек используют динамическое свойство repeat(auto-fill, minmax(280px, 1fr)), что позволяет им красиво перестраиваться на экранах мобильных телефонов без полос прокрутки.
Цветовая палитра вынесена в переменные :root для быстрой смены темы.

JavaScript (Vanilla ES6): Логика инкапсулирована внутри обработчика DOMContentLoaded.
Фильтрация регионов и личностей происходит мгновенно на стороне клиента за счет динамического управления стилями элементов (display = "none"/"block") и приведения строк к нижнему регистру (toLowerCase()), без отправки повторных запросов на сервер, что снижает нагрузку на бэкенд.

🚀 Автономный запуск фронтенда (для тестирования)
Если вам необходимо запустить и проверить работу страниц локально, минуя общую сборку через Docker:

Перейдите в терминале в папку фронтенда:


   cd frontend
Запустите встроенный веб-сервер Python для эмуляции хостинга:


   python -m http.server 8000
Откройте адрес в браузере: http://localhost:8000
